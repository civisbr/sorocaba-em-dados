Sobre o projeto

Dados públicos, explicados para quem vive a cidade.

O Sorocaba em Dados é uma iniciativa CivisBR que organiza informações públicas sobre Sorocaba (SP) em painéis simples, com origem rastreável, data de referência e limitações documentadas.

Nossos princípios

  • Nunca inventamos dados para preencher a página.
  • Todo número tem fonte primária e data de referência.
  • Cada dado é marcado como real, estimativa ou pendente.
  • Não fazemos rankings gerais nem conclusões que os dados não sustentam.

Como atualizamos

Cada painel tem um processo automático que baixa o dado da fonte oficial, valida e republica os arquivos. Se a fonte falhar, o site continua mostrando a última versão válida, sempre com a data de referência original.

Os arquivos de dados ficam disponíveis em cada painel. O código de geração está no repositório público.
